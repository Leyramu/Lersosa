# 配置管理层（Config Layer）

本包负责定义、加载和管理系统的运行时配置,通过 Protocol Buffers 提供强类型、可验证、可扩展的配置模型,为整个应用提供统一的配置入口。

## 主要功能

- 配置结构定义:使用 .proto 文件声明系统所需的所有配置项,确保类型安全与文档一致性。
- 多源配置加载:支持从 JSON、YAML、环境变量、命令行参数或远程配置中心加载配置。
- 配置验证与默认值:集成 protoc-gen-validate 等工具,在加载时自动校验合法性并填充默认值。
- 配置序列化/反序列化:支持将配置对象转为标准格式(如 JSON),便于日志记录、调试或 API 输出。
- 配置热更新:监听配置源变化,动态刷新配置并通知依赖组件。

## 与其他层的关系

- 被 `infrastructure` 层调用:在基础设施初始化阶段加载配置,并用于创建数据库连接、Redis 客户端、Elasticsearch 服务、HTTP 服务等。
- 为 `application` 层提供配置数据:Service 或 Use Case 可通过依赖注入获取所需配置子集。
- 独立于业务逻辑:不包含任何业务规则,仅提供数据结构与加载机制。
- 与 `adapter` 层分离:适配层定义 API 请求/响应协议,配置层定义系统运行参数,二者职责正交。

## 包结构

- `conf` - 配置管理层
    - proto - 配置协议
        - `conf.proto` - 配置协议定义
    - `conf.pb.go` - 配置协议编译后的文件
